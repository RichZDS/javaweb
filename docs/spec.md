# 功能说明

面向计算机专业学生的刷题 App。三批功能都要做：第一批先把五项核心功能跑通，第二批接着做，第三批是加分项。接口和判分、统计口径以 [`api.md`](api.md) 为准。

## 示例题库

三个考试（一级分类），全部原创题，至少 300 道、3 份以上试卷：

- 计算机考研 408：数据结构、计算机组成原理、操作系统、计算机网络
- Java 程序设计：基础语法、面向对象、集合与泛型、异常与 IO、多线程
- 数据库原理与 MySQL：关系模型、SQL 查询、事务与并发、索引与优化

## 关键规则（摘要）

- 每题提交一次就定下来，重复提交只算第一次；网络重试不会重复记录。
- 错题：提交没全对就收录；同一题只一条，累加错误次数；错题练习里连续答对 3 次移出，任何地方再错清零；移出后再错重新收录。
- 考试：服务器定开始和截止时间并存题目快照，手机拿不到答案；每题答案带版本号同步，截止后到的不计分；服务器每 30 秒结算到时的考试，App 关掉也能出成绩。
- 统计：时间存 UTC，按北京时间算天；背题和浏览不算作答。

## 页面（App）

底部 4 个页签：首页（兼题库入口）、考试、统计、我的。其余页面：登录、注册、选择目标考试、随机刷题设置、练习答题、练习结果、考前须知、考试答题、成绩单、错题本、收藏夹、练习记录、考试记录、搜题、每日一练、排行榜、设置。

## 非功能

- 常用接口目标 0.5 秒内返回，以实测为准。
- 密码 BCrypt；后台接口只给管理员；每人只能看自己的数据。
- Android 和 iPhone 都真机测过；接口走 HTTPS。
- 示例题每道都有来源说明（原创）。
