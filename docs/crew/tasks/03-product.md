### 第二项：原创示例题库（M2）
- 文件放 `backend/src/main/resources/seed/`，按 `docs/seed-format.md`：
  - `00-categories.json`：三个考试的完整分类树（见 spec「示例题库」，每个科目 3–5 个章节）。
  - `10-cs408-ds.json`、`11-cs408-co.json`、`12-cs408-os.json`、`13-cs408-cn.json`、`20-java.json`、`30-db.json`：题目。
  - `90-papers.json`：试卷，每个考试至少 2 份（1 份固定卷、1 份规则卷），共至少 6 份，时长 20–60 分钟，及格线约 60%。
- 数量：总数 ≥ 330 道。408 每个科目 ≥ 45 道，Java ≥ 90 道，数据库 ≥ 60 道；每个章节 ≥ 8 道。题型大致单选 55%、多选 20%、判断 15%、填空 10%；判断题对错各半。
- 计算机特色：Java 至少 20 道「看代码写输出」填空题，C 或 Python 至少 5 道，SQL 至少 5 道看语句写结果。代码必须真的跑过，答案就是实际输出：把每段代码存成文件，用本机 `java`（单文件直接运行）、`gcc`、`python3` 跑，SQL 用 Java 自带的 H2 或手工推演后写明推演过程。跑过的源码和输出存到 `/data/crew/qzd-5b1e/qb-verify/`，不进仓库。
- 原创：题目自己出，不照搬任何真题、教材习题或商业题库原文。题目要覆盖每个章节的核心考点，难度 1–5 分布合理。
- 每题必须有解析：说清为什么对，以及常见错误为什么错。
- 写 `scripts/validate-seed.mjs`（Node，无依赖）：检查 JSON 合法、key 唯一、引用存在、题只挂三级分类、选项数、答案格式、多选至少两个答案、判断只有 T/F、每章题量、规则卷题量够、固定卷引用存在、总数统计。通过时打印各考试、各题型数量并退出 0，有错逐条列出并退出 1。
- 自查：写完后随机抽 15% 的题重新独立做一遍，对不上的改正，把抽查结果（抽了多少、改了多少）写进报审。
