## 现场 / 锚点
- 题库已合入 main（d55af69）。工头随机抽 14 道，答案全对，但质量离“像真的备考题”还有距离：
  - 不少干扰项离谱到一眼排除，例如 `修改所有用户密码`、`自动增加主存容量`、`让密码不需要哈希`、`网络拥塞`（问局部性时）、`B O(n²) 必然`。粗略统计 408 的 180 道里约 48 道有这类选项，其他考试也有。
  - 难度偏低：难度 4–5 只有 28 道（7%）。408 里需要动手算的题偏少。

## 做法
1. **换掉离谱干扰项**：每个错误选项都应该是学生真的可能选的——常见误解、概念混淆、算错一步的结果、边界情况记反。不写和题目无关的选项，不用“永远”“总是”“必然”这类一眼可排除的绝对化措辞来凑数（题目本身就在考绝对化判断的除外）。全部 6 个题目文件都过一遍。
2. **加难度和计算题**：在不减少总题数的前提下，把一部分过于简单的题改写或替换，使难度分布大致为：1 级 ≤ 12%、2 级 ≤ 35%、3 级 ≥ 30%、4–5 级 ≥ 18%。408 每个科目至少 10 道需要计算或推演的题，例如：
   - 数据结构：二叉树遍历序列还原、哈夫曼编码带权路径长度、B 树高度和结点数、Dijkstra 或拓扑排序中间步骤、散列冲突后的探测次数、排序某一趟后的序列。
   - 组成原理：补码和浮点数表示、Cache 地址划分（标记 / 组号 / 块内偏移位数）、平均访存时间、流水线时空、指令格式和寻址计算。
   - 操作系统：调度算法的平均周转时间、银行家算法安全序列、页表和逻辑地址转换、页面置换缺页次数（FIFO / LRU / OPT）、磁盘调度移动距离。
   - 计算机网络：子网划分和可用主机数、CIDR 聚合、TCP 拥塞窗口变化、滑动窗口和信道利用率、CRC 余数、时延计算。
   - 数据库：给出表数据求 SQL 结果行数或值、函数依赖求候选键和范式、事务调度是否冲突可串行化。
   - Java：继承和多态下的方法分派结果、静态 / 实例初始化顺序、异常 finally 返回值、集合并发修改、线程可见性。
3. 计算题的答案要写出完整推演过程放在解析里；能用程序验证的（排序趟数、页面置换、子网、SQL 结果、Java 输出）用本机程序验证，源码和输出放 `/data/crew/qzd-5b1e/qb-verify/rework/`。
4. 试卷的规则题量仍要满足；`node scripts/validate-seed.mjs` 仍要通过。顺手把校验器加一条警告：选项文本命中“密码”“所有用户”“自动增加”等明显无关词时提示人工复核（只警告不报错）。
